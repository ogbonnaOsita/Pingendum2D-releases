# Pingendum2D: downloads

Pingendum2D is a 2D drafting program for macOS, Windows and Linux, by
Tiba Design. This repository holds its downloads only; the source is
not public.

## The beta

Pingendum2D 1.0 is in beta. Each beta is under
[Releases](../../releases), as a zip for each system.

**Opening it:** the beta isn't signed yet, so your system warns that it
comes from an unidentified developer.

- **macOS:** open the app once; when it's blocked, go to System Settings
  ▸ Privacy & Security and choose **Open Anyway**.
- **Windows:** when SmartScreen warns, choose **More info**, then **Run
  anyway**.
- **Linux:** make the program executable if needed, then run it.

**Reporting a problem:** in Pingendum2D, choose Help ▸ Report a Problem.
If you agree to send reports, crashes are reported for you when the
program next starts. Anything else: ogbonna.osita.21@gmail.com.

**Updates:** with your agreement, Pingendum2D checks `updates.json` here
at most once a day and tells you when a newer build is out.
